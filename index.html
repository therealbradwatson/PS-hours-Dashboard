TrellisPoint PS Hours Dashboard

      
A PM-facing browser-based tool that tracks project hours across all active Professional Services engagements by pulling live task estimates and milestone data directly from Teamwork. No manual lookups, no copy-paste — one click generates the full monthly hours view.

    


    

      
What It Does

      
Each week, this tool connects to Teamwork and calculates projected hours for all active Professional Services projects for the selected month. It produces two figures per project:

      

        
ColumnWhat It RepresentsHow It's Calculated

        
          

            Monthly Hours
            Total expected hours for the selected month — stable throughout the month as work progresses
            Hours already logged this month + hours still remaining on incomplete tasks due this month. Tasks due in a future month are pro-rated. As hours get logged, the "remaining" portion decreases by the same amount the "logged" portion increases — so the total stays consistent week over week.
          

          

            Budget Hours / Milestones
            For T&M: total hours remaining in the project time budget. For Fixed Fee: count of all open milestones.
            T&M Project time budget (capacity − used billable hours) in hours.  Fixed Fee Count of all open/incomplete milestones regardless of date.
          

        
      

      
The gap between these two columns for T&M projects shows where task estimates have drifted from the contracted budget hours — useful for spotting over- or under-estimated projects.

    


    

      
Calculation Logic by Project Type

      

        
Project TypeMonthly HoursBudget Hours / Milestones

        
          

            T&M
            
              Step 1: Sum all hours logged against the project in the selected month (across all tasks, including completed ones).


              Step 2: For each incomplete task with a due date in the selected month, add the hours still remaining: max(0, estimated − all-time logged). Tasks due in a future month are pro-rated: remaining ÷ months left. Tasks with no due date or past-due dates are excluded (PM should update them).


              Monthly Hours = Step 1 + Step 2. As hours are logged during the month, Step 1 increases and Step 2 decreases by the same amount — keeping the projection stable week over week.
            		
            
              Pulled directly from the Teamwork project time budget:

              (budget capacity − billable hours used) ÷ 60

              Only billable time entries count toward "used."
            		
          

          

            Fixed Fee
            
              Count of incomplete milestones with deadlines in the selected month.
            
            
              Count of all open/incomplete milestones for the project, regardless of deadline date.
            
          

        
      

    


    

      
How to Use It

      
    
        
  1. Connect to Teamwork — Click the connection button in the top-right corner and enter your Teamwork site URL and API key. Credentials are saved in your browser and reused automatically.
    2. 
        
  2. Select the month — Choose the month and year you are tracking. Defaults to the current month.
    3. 
        
  3. Select the week to update — Choose which week column in the output represents today's snapshot.
    4. 
        
  4. (Optional) Upload prior file — Upload last week's Excel file to carry forward prior week columns into the download. The tool reads and preserves those columns automatically.
    5. 
        
  5. Click Generate Projection — The tool fetches all active T&M and Fixed Fee projects from Teamwork, calculates hours, and displays the results.
    6. 
        
  6. Review the table — Compare Monthly Hours vs Budget Hours per project. The Δ column shows movement since the prior week if a prior file was uploaded.
    7. 
        
  7. Download Excel — Click Download Excel to export the hours view in the standard format, ready to share or file.
    8. 
      

    


    

      
Requirements & Setup

      
    
        
  • Teamwork API key — Go to Teamwork → Profile → Edit Profile → API Keys → Add New Token. Read-only access is sufficient.
    • 
        
  • Project categories — Projects must be assigned the category "T&M" or "Fixed Fee" in Teamwork (exact spelling, case-insensitive). Projects without a recognized category are excluded.
    • 
        
  • Teamwork time budget — For T&M Budget Hours to display correctly, the project must have a Time Budget configured in Teamwork (Project Settings → Budget).
    • 
      

    


    

      
Important Notes

      

        Task due dates must be current. The Monthly Hours column only includes tasks with due dates in the selected month. If a task is past-due or has no due date, it will not appear in the projection. Project Managers are responsible for keeping task due dates up to date in Teamwork.
      

      

        Monthly Hours vs Budget Hours. These two numbers will rarely match exactly for T&M projects. Task estimates are set by PMs and can drift from the contracted SOW hours over time. The Budget Hours column reflects the contract and is the authoritative figure. Use Monthly Hours to understand planned work distribution; use Budget Hours to understand total remaining capacity.
      

      
    
        
  • Only billable time entries count against the project budget. Internal or non-billable time is excluded from Budget Hours.
    • 
        
  • This tool runs entirely in your browser. No data is sent anywhere except directly to your Teamwork instance via the API.
    • 
        
  • Credentials are stored in localStorage in your browser and are never transmitted to any third party.
